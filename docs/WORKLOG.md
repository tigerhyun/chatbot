# 작업 일지

어떤 AI 도구로 작업했든, 끝날 때 **맨 위에** 기록을 하나 추가합니다. 다음에 다른 도구를 써도 여기만 읽으면 이어서 일할 수 있게 하는 것이 목적입니다.

- 개인 숫자(자산, 연봉 등)는 적지 않습니다. 이 저장소는 공개입니다.
- 매매일지 앱을 고쳤는데 게시하지 못했다면 `게시 필요`라고 적습니다. (게시는 Claude에서만 가능)

```
## YYYY-MM-DD · 사용한 도구
- 한 일:
- 확인한 것:
- 확인 못 한 것:
- 게시: 게시 완료 / 게시 필요 / 해당 없음
- 다음 할 일:
```
